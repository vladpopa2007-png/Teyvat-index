# Teyvat Index

An unofficial Genshin Impact companion web app.

Track daily domains, browse characters and weapons, manage your personal roster, plan ascensions, and more — all in a fast, lightweight page that works offline after the first load.

> **Note:** This is an unofficial fan project and is not affiliated with, endorsed by, or connected to HoYoverse or Genshin Impact in any way.

## Features

- **Daily Domain Tracker** — Talent books and weapon materials by day of the week
- **Character Index** — Filterable list with roles, builds, talent priority, and materials
- **Weapon Index** — Filterable list with passives and recommended users
- **Personal Roster** — Mark the characters and weapons you own (saved locally in your browser)
- **Resin Tracker** — Track current resin and time until capped
- **Ascension Planner** — Select characters and see estimated materials needed
- **Team Builder** — 4-slot team planner with basic resonance detection
- **Extra Tools** — Pity calculator, local specialties, weekly bosses, and more

All personal data (roster, resin, planner settings, etc.) is stored only in your browser using localStorage. Nothing is sent to any server.

## How to Run Locally

1. Download or clone this repository
2. Open `index.html` in any modern browser

No installation or build step is required.

## Project Status

This project is currently in the **building / early public phase**.  
Features and data are actively being improved. Feedback is welcome.

## Data

Character, weapon, and domain data is maintained manually.  
The goal is to keep it reasonably up to date with the current version of Genshin Impact. Some newer or unreleased content may be incomplete.

## Tech

- Single-page application (HTML + vanilla JavaScript + CSS)
- No frameworks required to run
- LocalStorage for user data
- Designed to work well on both desktop and mobile
