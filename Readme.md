# Teyvat Index

A centralized, developer-friendly data repository and index for the world of Teyvat (*Genshin Impact*). 

## Overview
**Teyvat Index** provides clean, structured, and easy-to-query datasets covering the seven nations, playable characters, weapons, artifacts, regional specialties, and game lore. It is designed to serve as a reliable backend source for Discord bots, fan wikis, build planners, and interactive web applications.

## Features
* **Structured Data:** Standardized JSON/CSV schemas for easy parsing and integration.
* **Comprehensive Coverage:** Includes entities across Mondstadt, Liyue, Inazuma, Sumeru, Fontaine, Natlan, and Snezhnaya.
* **Version Tracked:** Regularly updated to align with the latest *Genshin Impact* patches and content releases.
* **Lightweight & Modular:** Query specific categories (e.g., characters, materials, or enemies) without loading unnecessary overhead.
